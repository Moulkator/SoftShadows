SOFT SHADOWS

v1.5.1
- Renamed "Reset Defaults" to "Factory Reset" for Objects (was only for paths and walls before, objects were forgotten)
- Fixed the default opacity sliders (walls and paths) to be 0.6 in simple mode and 1.2 in realistic mode
- Fixed the realistic settings displayed in the Wall Tool and Path Tool (removed unused sliders and buttons and added the Blur slider)
- Fixed flickering in realistic mode when drawing paths or editing the bend
- In a multi-selection, changing an object's overlay setting will not affect all the other settings anymore
- Fixed undo not working with objects overlays after a delete
- Removed the layer choice in "Apply To All Walls" as it didn't make sense
- Added a white outline to the Apply To All choices for Paths and Walls

v1.5.0
- Fixed global bake mixing levels at reload
- Added a Realistic option for Paths and Walls shadows (needs more GPU than the simple mode)
- Added a Bend option for paths (adds an effect to create a bulge)
- Added a vertical overlay option for paths (goes along the path instead of starting at an end)
- Renamed "Reset Defaults" to "Factory Reset"

v1.4.2
- Optimized and improved "Extrude" shadows
- Fixed long shadows being cropped at export in high res

v1.4.1 - GitHub & Cartography Assets Release
- Added undo/redo support
- Added a "bake all" shadows option to render all shadows to a single overlay and gain fps
- Included Shadow Overlays (paths, objects) into the "enable/disable" option in the Shadow Settings tool
- Major fps optimization on multilevel maps
- Major fps optimization when using the "stopped by X" feature on objects
- Fixed the "stopped by X" feature not working with Auto-Bake
- Fixed various issues when cloning levels
- Compatibility with the mod version checker from _Lib

v1.4.0
- Shadow styles for Objects : "Offset" (default and current one), "Projected (Extrude)" and "Projected (Stretch)".
- Overlay Shadow for Objects (angle synced by default with the drop shadow angle of the same object)
- Shadows hidden under the asset are not generated anymore (may help gaining some fps)

v1.3.1
- Fixed shadows being applied on selection after a reload
- Fixed Soft Shadow button state not properly linked between the Object Tool and the Scatter Tool

v1.3.0
- Added radial offset for Paths ans Walls (offset following the drawing)
- Added Side Balance for Paths and Walls (asymmetric shadow)
- Added of a Shadows toggle button in the bottom floatbar (hides/displays shadows, only visual, no impact on memory usage)
- Fixed RAM issue when loading a map with lots of assets
- Added a button to Enable/Disable shadows per level in the Level Settings tool (disable = less memory usage)
- Added a Soft Shadow tool in the Effects Tab (under Lights):
	- Enable/Disable for All Levels/Current Level/Other Levels
	- Quality setting for all object shadows
	- Rendering options (Live, Bake Auto, Bake Manual)
- Removed the quality option in the Selection Tool
